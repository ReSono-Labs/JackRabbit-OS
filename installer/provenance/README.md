# Provenance

This directory records exact external sources used to design or build the
installer. A reviewed source is not automatically an adopted dependency or a
physically accepted capability.

`sources.json` is the machine-readable source ledger. `browser-apis.md` maps
browser APIs to runtime gates and explicitly separates API availability from
supported host/device tuples.

Rabbit's hosted wrapper is review-only because no public source revision or
license was discoverable. No Rabbit wrapper code is copied into JackRabbit.
